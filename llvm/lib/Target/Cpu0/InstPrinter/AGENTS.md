# InstPrinter

## Purpose
Converts `MCInst` objects into human-readable Cpu0 assembly text. Used during disassembly and the `asm` emission path of `llc`. Most of the printing logic is auto-generated by TableGen from the instruction `.td` definitions; only operand formatting and alias handling require manual code.

## Key Files

| File | Description |
|------|-------------|
| `Cpu0InstPrinter.h` | Declares `Cpu0InstPrinter : MCInstPrinter`; auto-generated methods (`getMnemonic`, `printInstruction`, `getRegisterName`) plus manual `printInst` and `printOperand` |
| `Cpu0InstPrinter.cpp` | Implements manual operand printing and delegates to TableGen-generated `printInstruction`/`printAliasInstr` |
| `CMakeLists.txt` | Registers this directory as the `Cpu0AsmPrinter` component |

## For AI Agents

### Working In This Directory

- `getMnemonic`, `printInstruction`, `printAliasInstr`, and `getRegisterName` are **auto-generated** — do not add logic there. They are defined in `Cpu0GenAsmWriter.inc` at build time.
- Custom formatting (immediate printing, memory operands, symbol references) goes in `printOperand` and any `printXxxOperand` helpers added to `Cpu0InstPrinter.cpp`.
- Adding a new instruction requires no changes here if the TableGen `AsmString` is correct — the generator handles it automatically.

### Testing Requirements

- Use `llvm-mc -triple=cpu0 -disassemble` or `llc -march=cpu0 -filetype=asm` to verify printed output.

### Common Patterns

- `printInst` calls `printAliasInstr` first; if no alias matches, falls back to `printInstruction`.
- `printOperand` handles `MCOperand` variants: immediate → decimal, register → `getRegisterName`, expression → `MAI.getSymbolSuffix`.
