# AsmParser

## Purpose

Parses LLVM IR text format (assembly language). Converts human-readable .ll files into in-memory LLVM IR module representations. Used by llvm-as, debugging tools, and frontends that emit IR as text.

## Key Files

| File | Description |
|------|-------------|
| `LLLexer.cpp` | Lexical analyzer for LLVM IR text format |
| `LLParser.cpp` | Recursive descent parser for LLVM IR grammar |
| `Parser.cpp` | Main parser orchestration |
| `AsmParserContext.cpp` | Parsing context and symbol management |

## For AI Agents

### Working In This Directory

1. Understand LLVM IR text format syntax (functions, basic blocks, instructions, types, attributes)
2. Familiarize with the IR grammar (consult LLVM Language Reference Manual)
3. Test parsing with various IR constructs: intrinsics, inline assembly, attributes, metadata
4. Handle edge cases: unnamed values, metadata cycles, function forward references
5. Verify error messages are clear and line numbers accurate
6. Test with IR generated by clang to ensure round-trip compatibility

### Key Patterns

- Lexer tokenizes input into LLVM keywords, identifiers, literals, operators
- Parser builds AST-like structures and emits into IR Module
- Symbol table tracks function, global variable, and type definitions
- Error recovery enables partial parsing for diagnostics
- Lazy loading of IR metadata for performance

## Dependencies

### Internal
- Depends on: LLVM Support, LLVM IR (lib/IR)
- Used by: llvm-as tool, IR utilities, frontends generating IR text
