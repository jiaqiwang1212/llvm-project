# Index IR

## Purpose
Core op, attribute, and dialect definitions for the Index dialect.

## Key Files
| File | Description |
|------|-------------|
| `IndexDialect.h` | Dialect class declaration |
| `IndexDialect.td` | Dialect definition |
| `IndexOps.h` | Op class declarations |
| `IndexOps.td` | ODS op definitions |
| `IndexAttrs.h` | Attribute declarations |
| `IndexEnums.td` | Enum definitions (comparison predicates) |

## For AI Agents

### Working In This Directory
- Edit `IndexOps.td` to add new index arithmetic ops
- Comparison predicates are defined in `IndexEnums.td`

## Dependencies
