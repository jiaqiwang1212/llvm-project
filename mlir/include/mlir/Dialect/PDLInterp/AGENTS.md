# PDLInterp Dialect

## Purpose
PDL Interpreter dialect — the bytecode-level IR that PDL patterns are compiled into. Provides low-level ops for pattern matching dispatch (switch, check-type, get-operand, etc.) executed by the PDL interpreter at pattern application time.

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `IR/` | Op definitions (see `IR/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- Do not write PDLInterp ops by hand; they are generated by PDLToPDLInterp conversion
- The interpreter executes these ops directly against IR nodes during pattern application

## Dependencies
- Generated from: PDL dialect
- Depends on: MLIR IR core
