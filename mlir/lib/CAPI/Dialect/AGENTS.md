# mlir/lib/CAPI/Dialect

## Purpose
Implements C API wrappers for all bundled MLIR dialects. Each `.cpp` file exposes dialect-specific type/attribute constructors, accessors, and op helpers as C functions, allowing language bindings to work with dialect types without C++ coupling.

## For AI Agents

### Working In This Directory
- Declarations are in `mlir/include/mlir-c/Dialect/<DialectName>.h`.
- When a dialect adds new types/attributes, add the corresponding C API here and in the header.
- `*Passes.cpp` files call `mlirRegisterXxxPasses()` — generated by TableGen from the dialect's pass `.td`.

### Common Patterns
- Type constructors follow `mlirXxxTypeGet(MlirContext, ...)` naming.
- Attribute constructors follow `mlirXxxAttrGet(MlirContext, ...)` naming.

## Dependencies

### Internal
- `mlir/lib/CAPI/IR/` — core C API utilities
- `mlir/lib/Dialect/` — C++ dialect implementations

### External
- `llvm/lib/Support` — ADT
